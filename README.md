# Temperature Data Analysis with SQLite

> Imports temperature readings into SQLite and calculates average Sunday and Thursday temperatures using SQL.

![Python](https://img.shields.io/badge/Python-3776AB?logo=python&logoColor=white)

## Skills demonstrated

Relational databases, data ingestion, parameterized SQL, and aggregate queries.

## Project files

[Python script](assignment5.py)

**Input:** `Assignment5input.txt` must be supplied separately; it is not currently included. Each line contains a day and numeric temperature. The script creates `temperature.db`; repeated runs append records.

## How to run

From the repository directory, use Python 3:

```sh
python assignment5.py
```
